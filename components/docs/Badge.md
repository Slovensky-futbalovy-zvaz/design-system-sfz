# Badge

Malý stavový štítok. `tone`: `neutral`, `info`, `success`, `warning`, `danger`, `brand`; `dot` pridá bodku.

- Text vždy pomenúva stav slovom („Uhradené“), farba je doplnok.
- `success` a `danger` sa líšia svetlosťou aj odtieňom; nikdy nepoužívajte len farbu na rozlíšenie.
- Nie je klikateľný; pre filtre použite `Chip`.
