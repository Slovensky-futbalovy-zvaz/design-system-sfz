# EmptyState

Prázdny stav zoznamu alebo výsledkov. `title` (čo tu bude), `description` (ako to vznikne), `action` (primárne tlačidlo), `icon`.

- Text píšte z pohľadu používateľa: „Žiadne podania“ + „Keď klub odošle podanie, zobrazí sa tu.“
- DataTable ho používa automaticky pri nulových výsledkoch.
