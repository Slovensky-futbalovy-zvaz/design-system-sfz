# Tabs

Prepínanie pohľadov v rámci jednej stránky. `variant="underline"` pre sekcie (posúvateľné), `segmented` pre 2–4 rovnocenné zobrazenia (iOS segmented control).

- Klávesnica: šípky, Home, End; `role="tablist"`. Panel označte `id="panel-<id>"` a `role="tabpanel"`.
- Na mobile `underline` nechajte scrollovať, neskracujte názvy.
- Tabs nemenia URL; pre navigáciu medzi stránkami použite NavBar/TabBar.
