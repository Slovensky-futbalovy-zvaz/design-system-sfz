# Select

Natívny `<select>` so štýlom systému – na mobile otvorí natívny picker, čo je zámer. Dodáte `options` (`{value,label}`), `placeholder` pre prázdnu prvú položku.

- Pre viac ako ~30 položiek (kluby, hráči) použite radšej Input s vyhľadávaním a vlastný zoznam výsledkov.
- Vždy s `label`; v toolbare DataTable stačí `aria-label`.
