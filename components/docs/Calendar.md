# Calendar

Mesačný prehľad s udalosťami (zápasy, tréningy, termíny). `value`, `onChange`, `month`, `events` (`{date, tone?}`), `min`, `max`.

- Týždeň začína pondelkom, nedeľa červená; mesiace po slovensky.
- Max. 3 bodky na deň; detail dňa zobrazte pod kalendárom alebo v Drawer.
- Bunky sú 40 px+ (touch target), klávesnica cez natívne tlačidlá.
